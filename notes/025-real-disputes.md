# 025 — 실제 분쟁에 넣어 보니 두 가지가 조용히 틀려 있었다

notes/024에서 분쟁 유형을 라벨하고 나니 할 수 있는 일이 하나 생겼다.
`EXCLUSION`으로 분류한 13건의 **쟁점 문장을 그대로 파이프라인에 넣는 것.**

이게 `rag/evaluate.py`의 18문항과 다른 점은 하나다. **18문항은 내가 썼다.**
약관을 읽고 만들었으니 약관의 말투가 배어 있다. 이건 금감원이 공개한
남의 문장이다.

## 처음 나온 숫자는 13/13이었다

전부 면책을 짚었다. 그런데 무엇을 짚었는지 읽어 보니 이랬다.

| 쟁점 | 걸린 조항 | 걸린 낱말 |
|---|---|---|
| **보조기** 구입비용이 보장 대상인지 | **HIV 감염 치료비** | `대상에` |
| **치과치료** 비급여가 지급사유인지 | **정신 및 행동장애** | `치료에서` |
| 압박고정용 재료대가 '보조기 등'인지 | **HIV 감염 치료비** | `목적` |
| 부담보 해제가 가능한지 | 건보공단 사후환급 | `가능한` |

**13/13은 거짓말이었다.** 맞는 조항을 짚은 것은 3건이고 나머지는 조사가
붙은 어절에 우연히 걸린 것이다. 정답률만 세고 무엇을 짚었는지 안 읽었으면
"실제 분쟁 13건 전부 적중"이라고 쓸 뻔했다.

## 1. 어절을 세니 조사 붙은 말이 희귀어로 보였다

면책검증은 **변별력 있는 표현**으로 후보를 거른다(notes/008). 약관 전체에서
문서빈도가 낮은 낱말만 쓰는데, 토큰을 `[가-힣]{2,}`로 어절 단위로 뽑고
있었다.

```
'대상'   -> 문서빈도 높음  -> 일반어로 걸러짐
'대상에' -> 문서빈도 낮음  -> 변별어로 통과   ← 같은 말인데
```

세어 보니 규모가 컸다.

| | |
|---|---|
| 변별어 | 4,528 |
| **그중 조사로 끝나는 어절** | **2,111 (46.6%)** |

`가격을`, `가입된`, `가액의`, `치료에서`, `대상에`… 사전의 절반이 이런
것이었다. 청구 서술에 `지급 대상에`만 있어도 아무 면책이나 걸렸다.

### 형태소 분석기를 쓰지 않은 이유

의존성이나 CPU 때문이 아니다. **떼는 규칙이 틀렸을 때 무엇이 사라졌는지
보이지 않기 때문이다.** 조사 목록을 손에 쥐고 있으면 `산부인과`가
`산부인`이 되는 사고를 눈으로 막을 수 있다.

그래서 조사·어미 24개를 목록으로 두고, **떼고 남은 어간이 두 글자 미만이면
떼지 않는다.** `치과`가 `치`가 되면 아무 데나 걸린다.

| | 이전 | 이후 |
|---|---:|---:|
| 변별어 | 4,528 | **3,166** |
| 조사로 끝나는 어절 | 46.6% | **6.0%** |

## 2. 병명 중간의 괄호에서 잘라 수식어만 남겼다

고치고 다시 돌렸더니 **확실(certain) 히트**가 하나 남았다.

```
[154] "청약일로부터 5년간 … 특정부위의 질병으로 …"
   -> [확실] 진단코드 F40가 약관이 정한 면책 범위에 든다
          정신 및 행동장애(F04∼F99)
```

부담보 해제를 묻는 쟁점에 **정신질환 면책이 확실로 걸렸다.** 확실 히트는
가드레일이 막지 않는다 — 코드로 확정된 부지급이기 때문이다. 근거 없는
부지급을 만드는 경로다.

`F40`이 어디서 왔는지 따라갔다. KCD 사전의 열쇠에 **`'특정'`** 이 있었다.

```python
_TRAILING_RE = re.compile(r"[,(].*$")   # 첫 괄호부터 끝까지 자른다
```

병명의 괄호가 **중간**에 있으면 앞머리 수식어만 남는다.

| 상병마스터의 이름 | 만들어진 열쇠 |
|---|---|
| `특정(개별) 공포증` | **`특정`** → F40 |
| `만성 (소아기) 육아종성 질환` | **`만성`** → D71 |
| `급성, 재발성 또는 아급성 홍채염` | **`급성`** → H20 |

`특정부위`, `급성 통증`, `만성 질환` — 청구 서술에 흔한 말이 전부 엉뚱한
코드를 물어 온다. 그리고 **코드가 붙으면 확실 면책이 된다.**

### 자르지 말고 덜어 낸다

괄호는 잘라 내는 것이 아니라 **덜어 내는 것**이었다.

```
"만성 (소아기) 육아종성 질환"  ->  "만성 육아종성 질환"   (이름이 오히려 좋아진다)
"특정(개별) 공포증"            ->  "특정 공포증"
"세포막수용체복합체[CR3]결손"   ->  "세포막수용체복합체 결손"
```

쉼표는 여전히 자르되(`질환, 상세불명`의 뒷가지는 수식어다), **자른 결과가
두 글자 이하로 줄면 자르지 않은 이름을 쓴다.** 쉼표가 나열일 때
(`급성, 재발성 또는 아급성 …`) 또 수식어만 남기 때문이다.

수식어 열쇠가 전부 사라지고 진짜 두 글자 병명은 남았다.

| 열쇠 | 이전 | 이후 |
|---|---|---|
| `특정` | F40 | **없음** |
| `기타` | C81, O35 | **없음** |
| `급성` | F23, H20, J22, J98 | **없음** |
| `만성` | D71, I51, K04 | **없음** |
| `치질` | K64 | K64 |
| `비만` | E66 | E66, R14 |

KCD 용어→코드 평가는 그대로다 — 구간 적중 7/10, 헛짚음 0/4(notes/013).
잃은 것 없이 오염만 걷어 냈다.

## 다시 잰 결과

`goldset/exclusion_eval.py`로 리포에 넣었다. 정답 표지는 손으로 정해
`exclusion_gold.jsonl`에 두었다.

| | 어간화 이전 | 이후 |
|---|---:|---:|
| 정답 조항을 짚은 사례 | 9/10 | **8/10** |
| 면책 아닌 3건의 오발동 | 3 | **2** |
| **총 히트** | **178** | **74** |
| 사례당 평균 히트 | 13.7 | **5.7** |

**정답률은 하나 잃었고 히트는 58% 줄었다.**

정답률만 보면 나빠진 것처럼 보인다. 그런데 이전의 9/10은 **아무 데나 다
걸려서** 그 안에 정답이 섞여 있던 것이다. 사례 하나에 "이 면책이 걸릴 수도
있다"를 열네 건 내놓으면 심사자에게는 아무것도 준 게 없다. 다섯 건이면
읽을 수 있다.

그래서 이 평가는 **정답률과 히트 수를 함께 낸다.** 하나만 보면 반대로
읽힌다.

## 남은 두 미스

**[155] 한방병원** — 청구서는 `한방병원`이라 쓰고 약관은 `한방치료`라 쓴다.
글자가 안 겹친다. notes/013의 용어 격차와 같은 문제이고, KCD 사전이 병명은
옮겨 주지만 진료 형태는 옮겨 주지 않는다.

**[163] 건강검진·백신·증명서 발급** — 면책 조항은 있는데
(`예방진료로서 질병·부상의 진료를 직접목적으로 하지 아니하는 경우`)
그 조항 본문에 `건강검진`이 없다. 세부 항목이 `목`으로 따로 떨어져 있고,
조항 본문에는 총칙만 있다. 조문 안의 `목`까지 후보로 세워야 잡힌다.

두 미스 모두 **덮어 두지 않고 그대로 센다.** 히트 0건은 "면책 없음"이
아니라 "못 찾았다"이고, 그 둘을 섞으면 지급 쪽으로 조용히 기운다.

## 배운 것

**정답률 하나만 세면 반대로 읽힌다.** 13/13도, 9/10도 실제로는 나쁜
상태였다. 무엇을 짚었는지 읽고 나서야 알았다.

018~023에서 되풀이한 것과 같은 모양이다 — 숫자를 얻은 순간 멈추지 말고
그 숫자가 가리키는 **원문을 읽어야 한다.** 이번에는 남의 문장을 넣어 본
것이 그 계기가 됐다. 내가 쓴 18문항으로는 끝까지 안 보였을 것이다.
