# 028 — 청구인을 위한 첫 가드레일

notes/027 끝에 이렇게 적었다.

> **제5조 ④ 자기부담 200만원 상한.** 이건 방향이 반대다. … 그래서 이 값을
> 모르면 우리 계산은 **과소**지급이 되고, 상한이 아니라 하한이 된다.
> … 방향이 다른 누락을 같은 깃발에 얹으면 그 깃발의 뜻이 흐려진다.

깃발을 하나 더 만들면 되는 일이었다.

## 조항

> ④ 제3조에서 정한 **입원**의 경우 급여의료비 중 보상금액을 제외한 나머지
> 금액(‘…본인부담금’의 20%에 해당하는 금액)이 계약일 또는 매년 계약해당일
> 부터 기산하여 **연간 200만원을 초과하는 경우 그 초과금액은** 제1항의
> 한도내에서 **보상합니다**

자기부담(본인부담금의 20%)이 연 200만원을 넘으면 넘은 만큼을 돌려준다.
즉 **자기부담이 연 200만원에서 멈춘다.**

급여 실손에만 있다. 판본 전체를 뒤져 확인했다 — 제5조에 `200만원`이
나오는 상품은 기본형 실손(급여)과 기본형 해외여행 실손 둘뿐이고, 비급여
특약에는 없다.

## 이 프로젝트의 모든 다른 조항과 방향이 반대다

지금까지 찾은 누락은 전부 한 방향이었다.

| 누락 | 결과 |
|---|---|
| 공제의 세 번째 항(notes/018) | 공제를 덜 뺀다 → **과다**지급 |
| 통원 1회 한도(notes/027) | 상한을 안 건다 → **과다**지급 |
| 올해 기지급액(notes/027) | 한도가 남은 줄 안다 → **과다**지급 |
| 통원 연간 횟수(notes/027) | 소진을 모른다 → **과다**지급 |

그래서 "모르면 **상한**"이라는 한 문장으로 다 덮였다. 자기부담 상한은
다르다 — **알수록 더 준다.** 모르면 우리 계산이 실제보다 **작다.**

```
급여 입원 300만원 청구, 보상 80%

  올해 자기부담 0원          -> 2,400,000원   (초과 없음)
  올해 자기부담 150만원      -> 2,500,000원   (10만원 더)
  올해 자기부담 200만원 소진 -> 3,000,000원   (전액)
  올해 자기부담 모름         -> 2,400,000원   ← 최대 60만원 덜 준 값
```

## 깃발을 나눴다

`Amount`에 `is_lower_bound`와 `missing_downward`를 더했다.

```python
# **반대 방향의 누락도 있다.** … 두 방향을 한 깃발에 담지 않는다. 담으면
# "상한"이라는 말의 뜻이 흐려지고, 청구인이 덜 받는 쪽 위험이 보험사가
# 더 주는 쪽 위험에 묻힌다.
is_lower_bound: bool = False
missing_downward: tuple[str, ...] = ()
```

근거 문장도 나눠 적는다.

```
올해 기지급액을 확인하지 못해 이 금액은 상한이다
올해 자기부담 누적을 확인하지 못해 이 금액은 하한이다 — 청구인이 더 받을 수 있다
```

둘 다 걸리는 청구도 있다. 그때 그 숫자는 상한도 하한도 아니고, 두 문장이
그대로 그렇게 말한다.

## 여섯 번째 가드레일

```
amount_lower_bound
  계산된 금액이 실제보다 작을 수 있다 — 청구인이 더 받을 수 있으므로
  심사자 확인이 필요하다
```

**지금까지 다섯 가드레일은 전부 보험사가 더 주는 위험을 막았다.** 근거
없는 지급(grounding), 계산 못 한 금액(amount_not_computed), 공제를 덜 뺀
금액(amount_upper_bound), 확인 못 한 면책(uncertain_exclusion).

이건 반대다. **청구인이 덜 받는 위험을 막는다.**

가드레일을 처음 설계할 때 "판정을 더 보수적인 쪽으로만 움직인다"고 썼는데,
그때 '보수적'은 암묵적으로 **지급하지 않는 쪽**을 뜻했다. 부지급도 사고지만
**과소지급도 사고다.** 금감원 분쟁조정사례에서 다투는 것의 상당수가
"덜 줬다"이지 "안 줬다"가 아니다.

여섯 다 여전히 판정을 `HUMAN_REVIEW`로만 움직인다. 가드레일이 지급을
만들어 내는 일은 없다 — 다만 이제 **지급을 막는 이유가 두 방향**이다.

## 데모

올해 기지급 200만원, **자기부담 누적 150만원**

```
보상비율 80%

  / 연간한도 잔액 48,000,000원 이내
-> PARTIAL  2,500,000원
```

같은 청구에서 자기부담 누적을 모르면 240만원이 나오고, 그 금액은
`HUMAN_REVIEW`로 넘어간다. **10만원을 덜 주는 대신 사람이 본다.**

293 passed.

## 배운 것

notes/027에서 "방향이 다른 누락을 같은 깃발에 얹으면 뜻이 흐려진다"고 쓰고
넣지 않았다. 그 판단은 맞았지만 거기서 멈춘 것은 틀렸다 — **깃발을 하나 더
만들면 되는 일**이었고, 만들고 나니 이 시스템에 없던 관점이 하나 생겼다.

"모르면 안전한 쪽으로"는 **누구에게 안전한지**를 정해야 뜻이 생긴다.
그걸 정하지 않으면 기본값이 조용히 보험사 쪽이 된다.
