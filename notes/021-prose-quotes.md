# 021 — 인용 예산의 절반이 표 테두리였다

notes/020에서 면책 인용문을 고치고 데모를 다시 봤다. 면책 쪽은 깨끗해졌는데
**보장 쪽 근거가 이랬다.**

```
[coverage] 제3조(보장종목별 보상내용)
    회사가 이 계약의 보험기간 중 보장종목별로 각각 보상하거나 공제하는 내용은
    다음과 같습니다.

    ┏━━━━┳━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

인용문 160자 중 알맹이는 첫 문장 하나고, 나머지는 표 테두리다. 첫 문장도
"다음과 같습니다"로 끝나는 **머리말**이라 그 자체로는 아무 정보가 없다.
정작 보장 내용은 저 표 안에 있는데, 보이는 것은 `┏━━━━┳`다.

## 얼마나

보장 조문 88개에 대해 인용 앞 160자에 괘선 문자가 들어가는지 셌다.

| | |
|---|---|
| 보장 조문 | 88 |
| 인용문에 표 테두리가 든 것 | **40 (45.5%)** |
| 최악 | 127자 중 **59자**가 테두리 (46%) |

절반 가까운 보장 근거가 이 상태였다. notes/020의 면책 문제(8.0%)보다
비율이 훨씬 높다.

## 왜 못 봤나

세 곳이 각자 다르게 자르고 있었다.

| 위치 | 방식 | 예산 |
|---|---|---|
| `coverage.py` | `text[:QUOTE_CHARS].strip()` | 160자 |
| `exclusion.py` | `_PREFIX_RE.sub(...)[:QUOTE_CHARS]` | 180자 |
| `mcp_server/server.py` | `" ".join(text.split())[:QUOTE_CHARS]` | 120자 |

같은 일을 세 번 다르게 구현해 놓으면 한 곳을 고쳐도 나머지가 남는다.
020에서 면책만 고친 것이 그래서다. **한 군데로 모았다** — `agents/quote.py`.

## 표를 지우지 않고 표가 있다고 말한다

첫 생각은 괘선 문자를 지우고 이어 붙이는 것이었다. 해 보니 셀 내용이
뒤엉켜 읽을 수 없는 문장이 된다.

```
보장종목 보상금액 입원 입원실료 입원제비용 입원수술비 법 에서 정한 의료급여 중
본인부담금 본인이 실제로 부 부를 본인이 부담하는 일부본인부담금과 요양급여 비용
```

**읽을 수 없는 인용문은 근거가 아니다.** 표를 산문으로 펴는 것은 별개의
문제이고(표 파서가 따로 있다 — notes/007), 인용문이 할 일이 아니다.

그래서 **표가 시작되는 지점에서 끊고, 표가 있다는 것을 표시한다.**

```
회사가 이 계약의 보험기간 중 보장종목별로 각각 보상하거나 공제하는 내용은
다음과 같습니다. …(표)
```

`…(표)` 세 글자가 테두리 59자보다 많은 것을 말한다 — "이 조문의 내용은
표에 있다"는 사실이다. 심사자는 조문 uid로 원문을 열면 된다.

## 표 앞에 알맹이가 없을 때

`<표1> 통원항목별 공제금액` 처럼 머리말이 24자도 안 되는 조문이 있다.
이때 억지로 문장을 만들지 않는다 — 있는 산문을 그대로 두고 표시만 붙인다.

```python
# 표 앞에 알맹이가 없으면(표가 곧 내용인 조문) 있는 산문을 그대로 두고
# 표시만 붙인다. 없는 문장을 만들어 내지는 않는다.
if table is not None and len(prose) < MIN_PROSE_CHARS:
    return (prose + TABLE_MARKER).strip()[:limit]
```

## 앞머리는 건드리지 않는다

020의 교훈을 함수 문서에 못박았다.

> 그래서 여기서 하는 일은 둘이다. **앞머리는 건드리지 않고**, 표가
> 시작되면 거기서 멈춘다.

020에서 지운 정규식이 다시 살아나지 않게, 왜 지웠는지와 무엇이 망가졌는지를
함수 옆에 남겼다. 지운 코드는 지운 이유가 함께 남아 있지 않으면 돌아온다.

## MCP 도구도 같은 규칙을 쓴다

`mcp_server`는 따로 자르고 있었다. 같은 함수로 바꿨다. 도구를 부르는 것이
사람이든 모델이든 근거 문장은 같아야 한다 — 모델에게 `┏━━━━┳`를 보여
주면서 근거를 판단하라고 할 수는 없다.

## 테스트

4건 추가.

- 표가 시작되는 곳에서 끊고 `…(표)`로 끝난다. 괘선 문자가 남지 않는다
- 표 앞에 알맹이가 없으면 표시만 붙인다
- 표가 없는 평문은 손대지 않는다
- 예산을 넘으면 `…`로 끊는다
