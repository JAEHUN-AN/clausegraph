# 044 — 병명이 아닌 열쇠와 앞 낱말에 붙은 짧은 열쇠

## 무엇이 보였나

해외 병원 시나리오 13건을 돌리다 상병마스터 사전(`kcd/index.py`)이 서술의
일상어에서 엉뚱한 코드를 만드는 것을 네 갈래가 따로따로 재현했다(2026-10-20).

| 서술 | 붙은 코드 | 왜 |
|---|---|---|
| 오른쪽 손목 골절 | **C34** 폐암 | `상엽, 기관지 또는 폐의 악성 신생물, 오른쪽` — 쉼표 절단이 조각을 남겨 전체 이름을 쓰고, 끝 낱말 `오른쪽`이 tail 열쇠가 됐다 |
| 발바닥이 찢어졌다 | **A66** 요스 | `벌레먹은 발바닥`의 tail `발바닥` |
| 주사를 맞았다 / 정맥주사 | **L71** 주사(酒皶) | 동음이의 — 청구서의 주사는 注射다 |
| 검사비만 청구합니다 | **E66** 비만 | `검사비` + `만`(뿐)의 `비만`. E66은 면책 코드라 **확실 면책 → DENIED** |

마지막 줄이 가장 나쁘다. 한 글자로 `HUMAN_REVIEW`가 `DENIED`로 뒤집혔고 2회
재현됐다. 사전 매칭은 결정론이라 "가끔"이 아니라 **매번** 틀린다.

## 바꾼 것

1. **`NON_DISEASE_KEYS`** — 측성·부위 낱말(`오른쪽`·`왼쪽`·`양쪽`·`발바닥`·`손바닥`)은
   열쇠로 쓰지 않는다. 병을 가리키지 않는다.
2. **`HOMONYM_KEYS`** — `주사`. 딸기코는 `딸기코증` 전체 이름으로 여전히 찾는다.
3. **짧은 열쇠의 앞 글자 검사** — 2글자 이하 열쇠는 앞 글자가 한글이면 맞은 것으로
   치지 않는다. 뒤 글자는 보지 않는다 — `비만으로`, `치질을`처럼 조사가 붙는다.
4. **동의어 `고도비만 → 비만`** — 3번의 대가로 붙여 쓴 진짜 병명 '고도비만'을 놓쳤다.
   기존 동의어 표 방식(공식 표기를 띄어 덧붙인다)으로 되살렸다.

형태소 분석기를 붙이는 쪽도 생각했지만 그만큼의 의존성을 들일 문제가 아니었다.
틀리는 방식이 네 가지로 셀 수 있었고, 하나씩 막았다.
