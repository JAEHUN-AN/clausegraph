# 044 — 병명이 아닌 열쇠와 앞 낱말에 붙은 짧은 열쇠

## 무엇이 보였나

해외 병원 시나리오 13건을 돌리다 상병마스터 사전(`kcd/index.py`)이 서술의
일상어에서 엉뚱한 코드를 만드는 것을 네 갈래가 따로따로 재현했다(2026-10-20).

| 서술 | 붙은 코드 | 왜 |
|---|---|---|
| 오른쪽 손목 골절 | **C34** 폐암 | `상엽, 기관지 또는 폐의 악성 신생물, 오른쪽` — 쉼표 절단이 조각을 남겨 전체 이름을 쓰고, 끝 낱말 `오른쪽`이 tail 열쇠가 됐다 |
| 발바닥이 찢어졌다 | **A66** 요스 | `벌레먹은 발바닥`의 tail `발바닥` |
| 주사를 맞았다 / 정맥주사 | **L71** 주사(酒皶) | 동음이의 — 청구서의 주사는 注射다 |
| 검사비만 청구합니다 | **E66** 비만 | `검사비` + `만`(뿐)의 `비만`. E66은 면책 코드라 **확실 면책 → DENIED** |

마지막 줄이 가장 나쁘다. 한 글자로 `HUMAN_REVIEW`가 `DENIED`로 뒤집혔고 2회
재현됐다. 사전 매칭은 결정론이라 "가끔"이 아니라 **매번** 틀린다.

## 바꾼 것

1. **`NON_DISEASE_KEYS`** — 측성·부위 낱말(`오른쪽`·`왼쪽`·`양쪽`·`발바닥`·`손바닥`)은
   열쇠로 쓰지 않는다. 병을 가리키지 않는다.
2. **`HOMONYM_KEYS`** — `주사`. 딸기코는 `딸기코증` 전체 이름으로 여전히 찾는다.
3. **짧은 열쇠의 앞 글자 검사** — 2글자 이하 열쇠는 앞 글자가 한글이면 맞은 것으로
   치지 않는다. 뒤 글자는 보지 않는다 — `비만으로`, `치질을`처럼 조사가 붙는다.
4. **동의어 `고도비만 → 비만`** — 3번의 대가로 붙여 쓴 진짜 병명 '고도비만'을 놓쳤다.
   기존 동의어 표 방식(공식 표기를 띄어 덧붙인다)으로 되살렸다.

형태소 분석기를 붙이는 쪽도 생각했지만 그만큼의 의존성을 들일 문제가 아니었다.
틀리는 방식이 네 가지로 셀 수 있었고, 하나씩 막았다.

## 남은 것

- `광견병`·`파상풍`은 진짜 병명이라 막지 않았다. "광견병 예방접종"에서 A82가 붙는다.
  면책 범위 밖이라 판정은 안 흔들리지만 화면에는 보인다. 진단서에서 코드를 뽑아
  `diagnosis_codes`로 넘기면 사전을 아예 부르지 않는다(notes/043) — 그쪽이 답이다.
- 증상 낱말(`통증`→R52, `출혈`→R58, `두근거림`→R00)은 맞는 코드다. 다만 진단이
  아니라 증상이라 화면에서는 진단 코드와 나눠 보여 주는 편이 낫다.

## 검토 반영 (2026-10-20) — 앞 글자 검사가 진짜 병명을 버렸다

"앞 글자가 한글이면 버린다"는 '검사비만'을 막았지만 **붙여 쓴 진짜 병명**도 버렸다.
검토가 접두어 15종 × 2글자 열쇠 228개를 돌려 3,396개 조합의 손실을 찾았고,
그중 면책 코드가 섞인 것은 과다지급이었다.

| 서술 | 전 | 앞 글자 검사 | 지금 |
|---|---|---|---|
| 수술후섬망, 알코올성섬망 | F05 | 없음 | F05 |
| 습관성유산, 자연유산 | O03 … | 없음 | O03 … |
| 만성치질 | K64 | 없음 | K64 |
| 복부비만, 소아비만, 고도비만 | E66 | 없음 | E66 |
| 급성폐렴, 만성위염, 초기위암 | J18, K29, C16 | 없음 | J18, K29, C16 |
| 검사비만, 치료비만, 준비만, 소비만 | E66 | 없음 | 없음 |

과다지급 사례: 급여 실손 2026-07-01 가입, "S62.0 손목 골절 수술 후 수술후섬망 발생,
5일 입원 청구 300만원" — main DENIED(F05), 앞 글자 검사 **PARTIAL 2,400,000원**,
지금 DENIED. 급여 실손의 면책 조문은 `F04∼F99`처럼 코드 범위만 적어 낱말 겹침으로도
다시 잡히지 않았다 — 위의 "놓쳐도 불확실 면책으로 간다"는 해외여행 상품에서만 맞았다.

고친 것: 짧은 열쇠 앞에 붙은 한글 덩어리가 **병명 수식어(`DISEASE_PREFIXES`)로
끝날 때만** 병명으로 친다. '고도비만' 동의어는 이 규칙에 흡수되어 뺐다. 목록은
닫혀 있다 — 늘릴 때는 그 수식어가 병명이 아닌 낱말을 만들지 않는지 본다.

수치는 그대로다 — 규칙 표 7/10·헛짚음 0/4, 실제 분쟁 8/10·오발동 2/3·평균 히트 5.7.

남은 것(검토 LOW-1): `NON_DISEASE_KEYS`는 닫힌 목록 다섯 개다. '왼쪽 다리'→T24,
'손가락 절단'→T23 같은 부위 낱말 잡음은 이번 변경 전부터 있던 것이고 남아 있다.
T는 상해 장이라 상해 규칙을 고르게 만들 수 있다. 구조화 입력(`diagnosis_codes`)을
쓰면 사전을 부르지 않으므로 ClaimLens 경로에는 닿지 않는다.
