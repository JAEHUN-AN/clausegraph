# 003 — 국가법령정보 API와 표준약관 확보 경로

OC 발급 후(자동 승인) 실제로 호출해 본 결과. **notes/000-scope의 가정 하나가
틀렸다는 것을 여기서 정정한다.**

> ## ⚠️ 정정 (2026-09-05, 같은 날 늦게)
>
> 아래 "HWP 파서가 필요하다. 우회로는 없다"는 **틀렸다.** 우회로가 있고,
> 그쪽이 더 낫다. 행정규칙 **본문 XML**의 `<별표내용>`에 표준약관 전문이
> CDATA 조각으로 통째로 들어 있다. 별표 목록 API만 보고 판단한 것이 실수였다.
>
> 게다가 HWP 경로는 **손실이 있다**. `pyhwp`의 `hwp5txt`는 표 내용을
> `<표>` 자리표시자로 버린다 — 별표15 한 건에서 **199개**. 표준약관의
> 장해분류표·수술분류표·보험금 지급표가 전부 표라서, 지급 판정의 핵심
> 데이터가 통째로 사라진다.
>
> | | HWP (pyhwp) | 본문 XML `<별표내용>` |
> |---|---|---|
> | 평문 | 272,695자 | **797,517자** |
> | `제N조` | 929 | **1,454** |
> | `자동차보험` 언급 | 24 | **43** |
> | 표 내용 | `<표>` 199개로 소실 | 텍스트로 보존 |
>
> (HWP는 2026-08-28 현행, XML은 2026-09-10 시행 — 시점이 달라도 표 소실이
> 차이의 대부분이다.)
>
> **결론: HWP 경로를 버린다.** pyhwp·six 의존성을 제거했다. 표준약관은
> 본문 XML 한 번의 요청으로 받는다. 수집 결과는 notes/004.

## (아래는 정정 전 기록) 표준약관은 API 텍스트가 아니라 HWP 첨부다

스코프 문서에 "표준약관이 법령정보센터에 개정 연혁과 함께 있으니 **PDF 파싱
없이 조문 단위로** 받을 수 있다"고 적었다. 절반만 맞았다.

- 별표 **목록**은 API가 XML로 준다 ✅
- 별표 **본문**은 API가 주지 않는다. `lawService.do?target=admbyl&type=HTML`은
  JS 뷰어 껍데기(3KB)이고, 그 안의 `admRulBylInfoP.do`도 마찬가지다.
- 실제 내용은 `flDownload.do?flSeq=...`의 **HWP 5.0 파일**뿐이다.
  `[별표 15] 표준약관(제5-13조제1항관련)(보험업감독업무시행세칙).hwp`, **1.7MB**

즉 HWP 파서가 필요하다. 우회로는 없다.

## HWP 추출은 된다 (pyhwp)

```
uv run --with pyhwp --with six hwp5txt <파일> --output <출력>
```

| 항목 | 값 |
|---|---|
| 추출 평문 | **272,695자** |
| `제N조` 출현 | **929회** |
| 표준약관 섹션(□) | **9개** |
| `<개정 ...>` 표기 | **328개** |
| `<신설 ...>` 표기 | **137개** |

- pyhwp 0.1b15는 Python **3.12·3.14 모두 임포트된다**(확인).
- 다만 `six`를 의존성에 선언하지 않아 따로 넣어야 한다 — pyhwp 쪽 결함이다.

### 9개 표준약관

생명보험 · 손해보험 · 질병·상해보험(손해보험 회사용) ·
기본형 실손의료보험(급여) · 실손 특별약관1(중증 비급여) ·
실손 특별약관2(비중증 비급여) · 기본형 해외여행 실손 · 해외여행 특별약관1·2

### 면책 조문이 실제로 있다

`보상하지 않는 손해` / `보상하지 않는 사항` / `보험금을 지급하지 않는 사유` —
이 프로젝트가 "벡터 검색으로 구조적으로 못 잡는다"고 주장하는 그 조문들이다.

### 개정 표기가 조문 단위로 붙는다

섹션 헤더에도 이력이 그대로 있다.

```
□ 생명보험 <개정 2005.2.15., 2008.3.26., 2010.1.29., ... 2025.3.31., 2025.6.30.>
```

## 시점 축은 확보된다

| 확인 | 결과 |
|---|---|
| 현행 세칙 | 1건 (`nw=1`), 일련번호 2200000108939, 발령 2026-08-28 |
| **연혁 세칙** | **192건** (`nw=2`), 1998년부터 |
| 연혁 본문 XML | 받힌다 — 4.3MB, `<별표>` 116블록, `flSeq` 234개 |
| 연혁 속 별표15 | 있다 — 번호 `0015`, 제목 `표준약관(제5-13조제1항관련)`, 시행일자 20251028 |

각 연혁 버전마다 그 시점의 표준약관 HWP를 받을 수 있다는 뜻이다.
"2015년 가입자에게는 2015년 약관이 적용된다"는 논증의 데이터가 실재한다.

## 신청 항목 점검

- `본문 XML`은 신청돼 있어 동작한다. `본문 HTML`은 미신청이라 에러 페이지가
  오는데, 필요 없으므로 재신청하지 않는다.
- `행정규칙 별표·서식`의 `본문 HTML`은 신청했지만 **쓸모가 없다**(뷰어 껍데기).
  실제로 필요한 것은 **목록 XML**에 들어 있는 `별표서식파일링크`다.
