# 데이터 출처와 이용조건

수집한 데이터는 **리포에 담지 않는다.** `data/`와 `models/`는 git에서
제외돼 있고, 아래 출처에서 직접 받는 스크립트만 들어 있다.

용량·라이선스 때문이기도 하지만, 더 큰 이유는 **원천이 갱신되기 때문**이다.
약관은 개정되고 코드표는 매년 바뀐다. 리포에 스냅샷을 박아 두면 언젠가
낡은 조항으로 판정하게 된다.

## 1. 보험 표준약관

| | |
|---|---|
| 출처 | [국가법령정보 공동활용](https://open.law.go.kr) — 보험업감독업무시행세칙 **별표15 표준약관**(제5-13조제1항관련) |
| 접근 | Open API. 회원가입 후 활용신청, 승인 1~2일 |
| 이용조건 | 비상업적 이용, 출처표시. 상업적 이용이 불가한 API가 있다 |
| 수집기 | `clausegraph.law.collect` |
| 규모 | 최신본 797,517자 / 조문 452개 / 약관 상품 14개. 연혁 183개 판본 |

`.env`의 `LAW_API_OC`에 인증키를 넣는다. 이 값은 호출 URL에 그대로 실려
나가므로 비밀키가 아니지만, **신청자를 식별**하므로 공개 저장소에 커밋하지
않는다. `.env`는 git에서 제외돼 있다.

신청할 API는 네 가지다.

- **행정규칙 별표·서식** — 목록 XML/JSON, 본문 HTML
- **현행 행정규칙** — 목록·본문 XML/JSON ← **표준약관 본문이 여기 있다**
- 대한민국 현행법령 — 목록·본문 XML (약관이 인용하는 법 조문)
- 판례 — 목록·본문 XML (근거 조항 라벨 보강)

표준약관 전문은 별표 API가 아니라 **행정규칙 본문 XML의 `<별표내용>`** 에
들어 있다. 별표 HWP 첨부로도 받을 수 있지만 그 경로는 쓰지 않는다 —
`pyhwp`가 표 내용을 버려서 장해분류표·수술분류표가 사라진다(notes/003 정정).

## 2. 금융감독원 분쟁조정사례

| | |
|---|---|
| 출처 | [분쟁조정사례](https://www.fss.or.kr/fss/job/fncCnflCase/list.do?menuNo=201195) |
| 접근 | 공개 게시판. 인증 없음, 서버 렌더 HTML |
| 이용조건 | 출처표시 |
| 수집기 | `clausegraph.goldset.collect` |
| 규모 | 보험 권역 160건. 범위 내(질병·상해·실손·생명) 97건 |

평가셋으로 쓴다. 사례는 청구인을 `A씨`·`민원인`으로 익명화해 게시되며,
수집한 160건에서 주민등록번호·전화번호·계좌번호는 **0건**이다(공개 전 확인).

요청 간 0.5초 지연을 둔다. 공공 사이트다.

## 3. KCD 코드표 (건강보험심사평가원 상병마스터)

| | |
|---|---|
| 출처 | [공공데이터포털](https://www.data.go.kr/data/15067467/fileData.do) |
| 접근 | 파일데이터. **로그인 불필요** |
| 이용조건 | **공공저작물 제1유형(출처표시)**, 무료 |
| 수집기 | `clausegraph.kcd.collect` |
| 규모 | CSV(CP949) 5.4MB, 47,798행 / 코드 21,299개 |

컬럼: 상병기호·한글명·영문명·완전코드구분·주상병사용구분·법정감염병구분·
성별구분·상한/하한연령·양한방구분.

여분 26,499행이 **동의어**다 — 한 코드에 이름이 여럿 달린다. 별도 색인을
수집할 필요가 없었다(notes/013).

다운로드는 두 단계다. `POST /tcs/dss/selectFileDataDownload.do`로 메타데이터를
받아 진짜 `atchFileId`를 얻고, `GET /cmm/cmm/fileDownload.do`로 파일을 받는다.
상세 페이지 HTML에서 긁은 id를 쓰면 **다른 첨부**를 받는다.
