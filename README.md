# clausegraph

> 보험 약관 지식그래프 + 다중 에이전트 지급심사 보조.
> 청구 건을 넣으면 지급/부지급/추가서류 판정과 **근거 약관 조항**을 낸다.

스코프와 설계 근거: [docs/000-scope.md](docs/000-scope.md)

## 상태

W1 진행 중.

- 골드셋 수집 완료 — 금감원 분쟁조정사례 **160건**(보험 권역), 섹션 분해
  158건. 범위 내(질병·상해·실손·생명) **97건**. → [notes/001](notes/001-goldset-collection.md)
- Tier A 라벨링 완료 — 규칙 정확도 **90.0%**(독립 표본 20건), 확신도 HIGH 구간은 29/29. → [notes/002](notes/002-tier-a-labeling.md)
- 국가법령정보 API 확보·검증 완료 — 표준약관은 **HWP 첨부만** 제공되며
  pyhwp로 272,695자 추출 확인. 연혁 **192개 버전**으로 시점 축 확보.
  → [notes/003](notes/003-law-api-and-hwp.md)
- 표준약관 수집기 완료 — 본문 XML의 `<별표내용>`에서 별표15를 꺼낸다.
  최근 개정 10건 = **표준약관 4개 버전**(내용 해시로 묶어 적용 구간 부여).
  → [notes/004](notes/004-standard-terms-collection.md)
- 조문 파서 완료 — 최신본 **조문 452개 / 약관 상품 14개**(목차와 일치),
  면책 조문 18개, `<개정>` 표기 174개. → [notes/005](notes/005-clause-parser.md)
- 그래프 적재 완료 — Neo4j에 조문 1,706 · 호 2,371 · 면책 68 · 버전 4.
  가입일로 적용 약관을 되살리는 질의가 동작한다. → [notes/006](notes/006-graph-load.md)
- 실손 면책 표 파서 완료 — 표에서 면책 사유 **351개** 추출(보장종목 20).
  셀 줄바꿈에서 사라진 공백을 문서 자신을 사전으로 복원, 오류 **0.73%**.
  → [notes/007](notes/007-exclusion-table-parser.md)
