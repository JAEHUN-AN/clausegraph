- 대상: 범위 내 97건에서 시드 20260905으로 뽑은 30건

  규칙이 낸 답을 보지 않은 상태에서 작성했다(워크시트에 규칙 답을 싣지 않은 이유).

## 라벨 정의

| 라벨 | 뜻 |
|---|---|
| PAID | 보험금 지급이 타당하다는 결론 |
| DENIED | 지급 거절이 타당하다는 결론 |
| PARTIAL | 감액·삭감된 금액이 지급됨 |
| NOT_CLAIM | 보험금 지급 판정 사안이 아님 (계약 해지·보험료·절차) |

## 판독 중 드러난 경계 사례

- **78** — 추가 서류 제출 요구. 지급 여부가 확정되지 않았다. 이 프로젝트의
  판정 체계(지급/부지급/**추가서류요청**)에는 세 번째 값이 있는데 Tier A
  라벨 체계에는 없다. 라벨 스킴에 `NEEDS_DOCS`를 추가할 근거다.
- **22** — 민감정보 미동의로 처리 보류. 78과 같은 성격.
- **62** — 고지의무 위반 해지와 보험금 거절이 함께 걸린 사안. 계약 사안으로도
  볼 수 있으나 쟁점이 보험금 부지급이라 DENIED로 판독했다.
- **132** — 기지급 보험금 공제. 지급은 이뤄졌으나 다투는 부분은 부지급이라
  PARTIAL이 아닌 DENIED로 판독했다. 18·39·82·111(감액 사안)과 경계가 얇다.
